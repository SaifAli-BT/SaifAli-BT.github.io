Live NCBI Gene workflow: ESearch resolves the GeneID, ESummary reads metadata, EFetch reads the Gene Table and nucleotide sequence through linked RefSeq records. NCBI is rate-limited here to one request about every 400 ms. No coordinates or annotations are fabricated.

Embedded enzyme list contains common restriction endonucleases. Positions use 1-based sequence coordinates; cut-site notation is relative to the recognition motif.
Paste a coding sequence in-frame. Codon usage is computed directly from the sequence. “Rare” here is defined relative to the most frequent codon in the entered sequence, not to a species-wide codon-use table.
Compares two sequences, reports substitutions/insertions/deletions, and translates frame +1. This is an educational comparison, not a clinical variant interpretation service.
Client-side PDF editor. Text-layer PDFs can be clicked and edited in detected text lines; edits are patched into the original PDF with local overlays so untouched page content is not reflowed. Scanned PDFs can be OCR’d first. This approach preserves layout as a practical browser workflow, but it is not a byte-identical semantic PDF editor like a native desktop PDF engine.
